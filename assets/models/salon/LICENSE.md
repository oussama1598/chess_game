# Geometry-backed salon assets

The prop meshes in this directory are derived from the following Poly Haven
assets, all released under CC0 1.0 Universal:

## Wooden Chair 01

- Source: https://polyhaven.com/a/WoodenChair_01
- Author: Jake Mobley
- Runtime file: `wooden_chair.obj`
- Source geometry: Poly Haven 1K glTF package

## Fancy Picture Frame 01

- Source: https://polyhaven.com/a/fancy_picture_frame_01
- Authors: Rob Tuytel and Rico Cilliers
- Runtime files: `picture_frame.obj`, `picture_canvas.obj`
- Source geometry: Poly Haven 1K glTF package

The source glTF meshes were evaluated, centered around a shared asset origin,
grounded on Y=0, triangulated, and converted from Z-up to Y-up by
`scripts/export_salon_props.py`. UV coordinates and authored normals are
preserved. No proprietary model assets are included.

Poly Haven license: https://polyhaven.com/license
