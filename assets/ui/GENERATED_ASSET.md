# Launcher backdrop

`launcher_backdrop.jpg` and the active composition
`launcher_backdrop_v2.jpg` were generated for this project with OpenAI's
built-in image-generation tool on 2026-09-06, then cover-cropped to 1000×1180
and stored as 88-quality progressive JPEGs. The second version raises the hero
knight so it remains legible behind the New Game controls.

The prompt requested a dark, portrait-format, premium 3D chess still with one
satin-ivory knight, a crafted walnut board, a midnight-navy salon, calm space
for controls, and no text, logos, coordinates, HUD, guides, icons, watermarks,
or reflection hotspots. Its art direction is derived from this project's salon
scene; provenance for the underlying CC0 model and texture references is
recorded in the adjacent asset license files.

The Qt launcher paints its own navy readability overlay, lower-right warm glow,
and vertical contrast gradient over this source image at runtime.
