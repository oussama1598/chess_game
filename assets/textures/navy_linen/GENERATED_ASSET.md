# Navy linen wall texture

Generated for this project with OpenAI's built-in image-generation tool on
2026-09-05. The prompt requested a seamless, square, deep-midnight-navy woven
linen wall texture with subtle charcoal damask detail, flat lighting, and no
objects, perspective, text, logos, highlights, shadows, or vignette.

The texture is used by the renderer's physical salon wall geometry. A small
neutral specular map is bundled beside it for the engine's two-texture PBR
workflow.
