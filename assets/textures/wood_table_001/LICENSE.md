# Wood Table 001 texture

The diffuse and roughness maps in this directory are the 2K JPG versions of
**Wood Table 001** from Poly Haven:

- Source: https://polyhaven.com/a/wood_table_001
- Author: Rob Tuytel / Poly Haven
- License: [CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/)

`wood_table_001_spec_2k.jpg` is derived locally by inverting and contrast
normalizing the roughness map for the renderer's legacy specular workflow.

`wood_table_001_diff_cinematic_2k.jpg` is derived locally from the source
diffuse map by reducing brightness, contrast, and saturation for the game's
cinematic tabletop treatment.
